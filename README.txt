# Oosha / Romantic Mobile Site

الملفات:
- index.html
- style.css
- script.js

## التشغيل
افتح `index.html` في المتصفح.

## تغيير كلمة السر
افتح `script.js` وعدّل:
CONFIG.password

## إضافة الأغنية
ضع ملف mp3 داخل نفس مجلد الموقع، ثم عدّل:
CONFIG.audioFile = "song.mp3";

## تغيير النص
يمكن تعديل النصوص مباشرة من `index.html` أو مصفوفة `messages` في `script.js`.

## ملاحظة
التصميم مبني على المشاهد الظاهرة في الفيديو المرفوع، مع جعل الصور/الأغنية قابلة للاستبدال لأن الفيديو لا يوفّر الملفات الأصلية منفصلة.
